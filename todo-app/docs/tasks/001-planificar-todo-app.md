## Entrada

Una aplicación web de lista de tareas de una sola página. Sin frameworks ni paso de build: vanilla JS, se abre con `index.html`. Permite crear tareas, marcarlas completadas, editarlas y borrarlas; ver cuántas quedan pendientes; limpiar las completadas; filtrar la vista por todas / pendientes / completadas; y las tareas persisten al recargar la página.
