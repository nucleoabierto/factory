# Acabado visual de la UI

## Lecciones

- **Un elemento nuevo de la interfaz llega con su acabado visual completo: regla CSS coherente con la paleta, nombre accesible, métricas uniformes con sus hermanos y el mismo patrón de comportamiento (ocultamiento, hover).** Por qué: tres entregas llegaron funcionales pero incompletas en lo visual —un `<select>` de listas sin regla CSS ni `aria-label`, botones de glifos con tamaños distintos por la métrica de cada carácter y un campo de fecha siempre visible que rompía el patrón hover de su fila—; el usuario pidió revisar lo visual antes de aprobar en cada caso.
