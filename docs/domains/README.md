# Dominios

Índice de los dominios del proyecto, mantenido por el skill `documentar-dominio`. Cada dominio se documenta en un archivo `NNN-slug.md` siguiendo la plantilla del skill: propósito, lenguaje ubicuo con anclas al código, modelo, fronteras, decisiones relevantes y estado de salud.

Reglas del índice:

- Todo documento de dominio figura aquí; un documento sin entrada se da de alta o se elimina.
- Formato de cada línea: `- NNN-slug.md — nombre del dominio`. La numeración es una serie propia de dominios: el siguiente número disponible en el directorio.
- Un hecho del dominio vive en un solo documento; los demás lo referencian.

## Dominios

- 001-ciclo-de-tareas.md — Ciclo de tareas: índice TODO.txt, ejecución en rama, pull request con dos puertas humanas y merge
- 002-flujo-idea-a-tarea.md — Flujo de idea a tarea: propuestas, borradores, épicas y roadmap
- 003-subflujo-desarrollo.md — Sub-flujo de desarrollo: contexto, conectividad, planeación, ejecución y revisión del diff
- 004-documentacion-viva.md — Documentación viva: dominios, producto, decisiones, investigación y guía de estilo
- 005-aprendizaje.md — Aprendizaje por experiencias: registro, consolidación y consulta por disparadores
