# Anclas y trazabilidad

## Lecciones

- **En la documentación de dominio, el ancla apunta a lo que cambia (el código) y la procedencia es un campo aparte.** Por qué: al diseñar el glosario del dominio, el ancla apuntaba solo al código y el usuario preguntó si no sería mejor anclar a la tarea; el ancla existe para detectar deriva —las tareas son documentos históricos inmutables que no delatan cambios—, mientras que la tarea o épica que introdujo el concepto es trazabilidad complementaria, útil como campo «Origen» opcional.
