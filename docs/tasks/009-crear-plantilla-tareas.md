# Crear plantilla de tareas

## Estado

[x] Completada

## Objetivo

Usando los principios de `revisar-redaccion.md` y `pulir-escritura.md`, y las lecciones aprendidas al ejecutar las tareas anteriores, generar un formato de tareas que permita capturar el objetivo de una tarea, las dependencias y su resultado esperado, de forma que sea posible no solo ejecutarla sino también evaluar la calidad del resultado.

## Dependencias

- `docs/tasks/008-aplicar-mejoras-pulir-escritura.md`

## Entrada

- Lecciones aprendidas de las tareas 001-008.
- Plantilla `docs/templates/task.txt`.

## Resultado esperado

- `docs/templates/task.txt` con la plantilla de tareas.

## Criterios de calidad

- La plantilla incluye campos para estado, objetivo, dependencias, entrada, resultado esperado, criterios de calidad, procedimiento sugerido y notas.
- Los criterios de calidad son verificables y permiten evaluar el resultado.
- La plantilla es reutilizable para cualquier tarea.

## Procedimiento sugerido

1. Analizar las lecciones de las tareas anteriores.
2. Diseñar la plantilla con campos que capturen objetivo, dependencias, resultado y calidad.
3. Guardar en `docs/templates/task.txt`.
