# Investigar mejores prácticas para mensajes de commit

## Estado

[x] Completada

## Objetivo

Investigar las mejores prácticas para escribir mensajes de commit en Git. Definir principios, convenciones y criterios de calidad que sirvan de base para un skill de commits.

## Dependencias

- Ninguna

## Entrada

- Acceso a web para investigar fuentes públicas.
- Conocimiento del estándar Agent Skills y las mejores prácticas para skills (docs/research/skills-best-practices.md).

## Resultado esperado

- `docs/research/commits-best-practices.md` con un destilado de principios, convenciones y criterios de calidad para mensajes de commit.

## Criterios de calidad

- La investigación cubre convenciones establecidas (Conventional Commits, Git man page, kernel de Linux, etc.).
- Distingue reglas universales de preferencias de proyecto.
- Define qué hace un buen mensaje de commit: estructura, longitud, tono, contenido.
- Cubre casos especiales: fixes, reverts, merges, squash, scopes.
- El documento pasa revisión de redacción y pulido mecánico.
- El usuario aprueba el resultado antes de cerrar la tarea.

## Procedimiento sugerido

1. Investigar fuentes públicas sobre mensajes de commit.
2. Sintetizar principios universales y convenciones establecidas.
3. Redactar `docs/research/commits-best-practices.md`.
4. Aplicar revisión de redacción y pulido mecánico secuencialmente.
5. Presentar al usuario para aprobación.

## Notas

- El documento debe ser un destilado, no una recopilación exhaustiva de fuentes.
