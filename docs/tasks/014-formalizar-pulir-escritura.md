## Objetivo

Realizar el mismo proceso de transformación que con `revisar-redaccion.md`, aplicando las reglas investigadas para convertir `pulir-escritura.md` en un skill formal. Validar con el usuario la forma final.

## Dependencias

- `docs/tasks/012-investigar-skills.md`
- `docs/tasks/013-formalizar-revisar-redaccion.md`

## Entrada

- `docs/research/skills-best-practices.md`
- `pulir-escritura.md`
- `revisar-redaccion.md` (ya transformado, como referencia)

## Resultado esperado

- `pulir-escritura.md` transformado en un skill formal según las mejores prácticas investigadas.
- Validación del usuario sobre la forma final.

## Criterios de calidad

- El skill cumple con la estructura y campos definidos en `docs/research/skills-best-practices.md`.
- El skill es agnóstico al arnés.
- El contenido sustantivo (categorías de corrección, procedimiento) se preserva.
- Aprobado por el usuario.

## Procedimiento sugerido

1. Leer `docs/research/skills-best-practices.md` y `pulir-escritura.md`.
2. Proponer la transformación al usuario.
3. Iterar según feedback.
4. Aplicar la transformación.
5. Validar con el usuario.
