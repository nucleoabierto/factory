[ ] Pendiente

## Objetivo

Investigar cómo organizar `TODO.txt` agrupando tareas por hitos, fases o proyectos, y proponer un formato concreto que mantenga la simplicidad del índice actual.

## Dependencias

- Ninguna

## Entrada

- `TODO.txt` en su formato actual.
- `docs/research/skills-best-practices.md` como referencia de estilo.

## Resultado esperado

- Documento de investigación en `docs/research/` con análisis de opciones de organización por hitos y una recomendación de formato para `TODO.txt`.

## Criterios de calidad

- Analiza al menos tres enfoques distintos (p. ej. secciones con encabezados, prefijos en cada línea, archivos separados por hito).
- Evalúa compatibilidad con el formato actual de `TODO.txt` y con el skill `ejecutar-tareas`.
- La recomendación es concreta: incluye el formato propuesto con un ejemplo.
- Pasa revisión de redacción y pulido mecánico.

## Procedimiento sugerido

1. Examinar el formato actual de `TODO.txt` y cómo lo consume el skill `ejecutar-tareas`.
2. Investigar enfoques de organización por hitos o fases.
3. Evaluar cada enfoque against el formato actual y el skill.
4. Proponer una recomendación con ejemplo.
5. Aplicar revisión de redacción y pulido mecánico.

## Notas

- El formato actual es plano: una lista de tareas con estado. La organización por hitos debe añadir estructura sin romper la simplicidad.
