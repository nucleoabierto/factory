# Escribir documento de visión del proyecto

## Estado

[x] Completada

## Objetivo

Escribir un documento de visión del proyecto a partir de la definición de la tarea 026, adaptando el contenido al formato y estilo del proyecto. El borrador se presenta al usuario para aprobación antes de finalizar.

## Dependencias

- 026

## Entrada

- Documento de definición del proyecto de la tarea 026.
- Decisiones de diseño de la tarea 025 como contexto.
- `docs/research/skills-best-practices.md` como referencia de estilo.

## Resultado esperado

- Documento de visión en `docs/` que articule propósito, objetivos, alcance y dirección del proyecto.

## Criterios de calidad

- Articula propósito, objetivos, alcance y dirección del proyecto.
- Usa el formato y estilo del proyecto (Markdown, español, estructura de secciones).
- El borrador se presenta al usuario para aprobación antes de finalizar.
- Pasa revisión de redacción y pulido mecánico.

## Procedimiento sugerido

1. Partir del documento de definición de la tarea 026.
2. Redactar el documento de visión adaptando el contenido al formato del proyecto.
3. Aplicar revisión de redacción y pulido mecánico.
4. Presentar al usuario para aprobación.

## Notas

- La visión es la dirección aspiracional del proyecto; la definición es el estado actual acordado. No confundir.
