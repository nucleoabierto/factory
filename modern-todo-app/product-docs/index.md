# modern-todo-app — Documentación de producto

modern-todo-app es una aplicación web de lista de tareas que funciona en el navegador: se abre y se empieza a apuntar. Todo lo que se escribe se conserva entre visitas en el propio navegador.

## Índice

- **Funcionalidades**
  - [Lista de tareas](funcionalidades/001-lista-de-tareas.md) — capturar, completar, eliminar y marcar todas
- **Referencia**
  - [Estado persistido](referencia/estado-persistido.md) — qué guarda la aplicación en el navegador y en qué formato

## Qué hay detrás

El modelo y sus reglas —qué es una tarea y sus invariantes— están documentados en el documento de dominio `docs/domains/001-lista-de-tareas.md` del propio proyecto. Esta documentación cubre el comportamiento observable: qué hace la aplicación y cómo usarla.
